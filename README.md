# 🦷 Dentalfy — پلتفرم آموزشی تخصصی دندانپزشکی (آکادمی RMO)

**Dentalfy** یک وب‌اپلیکیشن تمام‌عیار (Full-Stack) برای آموزش دروس دندانپزشکی، انتشار جزوات و مقالات تخصصی، اشتراک‌گذاری فایل‌های PDF و ویدیوهای آموزشی است. این پروژه را از پایه با تمرکز روی رابط کاربری تمیز و مدرن (RTL)، ویرایشگر محتوای بلوکی، پنل مدیریت دو‌سطحی (مدیر و نویسنده) و لایه‌های امنیتی سمت سرور طراحی و پیاده‌سازی کرده‌ام.

---

## ✨ امکانات کلیدی

### بخش عمومی (کاربران و دانشجویان)
- **صفحه اصلی داینامیک (`index.html`)**: معرفی دروس اصلی دندانپزشکی، آخرین پست‌ها با فیلتر دسته‌بندی و جستجوی زنده، کتابخانه فایل‌ها و فرم درخواست اکانت نویسنده.
- **صفحات اختصاصی درس و پست (`course.html` و `post.html`)**: نمایش سرفصل دروس، پست‌های مرتبط، پخش‌کننده ویدیو (YouTube، Aparat و MP4) و دانلود/پیش‌نمایش فایل‌های PDF.
- **پالت جستجوی سریع (`Ctrl + K`)**: دسترسی سریع به دروس، مقالات و جزوات از هر جای سایت.
- **حالت شب و روز (Dark / Light Mode)**: تغییر تم همراه با ذخیره خودکار انتخاب کاربر.

### پنل مدیریت و نویسندگان (`panel/`)
- **ویرایشگر بلوکی محتوا**: ساخت پست با بلوک‌های متن، تیتر، تصویر، ویدیو، فایل PDF، نقل‌قول و لیست.
- **گردش کار تأیید محتوا**: نویسنده پست را ثبت و برای بررسی ارسال می‌کند (`pending`) و مدیر پس از بازبینی آن را منتشر (`published`) یا با ثبت دلیل رد (`rejected`) می‌کند.
- **مدیریت نویسندگان و درخواست‌ها**: بررسی فرم‌های درخواست عضویت نویسندگان، صدور اکانت، مدیریت پروفایل و بازنشانی رمز عبور.
- **تنظیمات برندینگ سایت**: تغییر نام سایت، متون Hero، آمارها، رنگ اصلی، ایمیل تماس و فوتر مستقیم از داخل پنل.
- **ذخیره‌سازی فایل‌ها**: پشتیبانی از آپلود و نگهداری فایل‌های رسانه‌ای و PDF تا ۲۵ مگابایت.

### امنیت و بک‌اند (`server/`)
- **احراز هویت امن**: رمزنگاری پسورد با `bcryptjs` و مدیریت نشست با **JWT** در کوکی‌های `HttpOnly`.
- **احراز هویت دو‌مرحله‌ای (TOTP / 2FA)**: تولید کلید و QR Code سازگار با اپلیکیشن‌های Authenticator به همراه کدهای بازیابی.
- **محافظت در برابر حملات**: محافظت **CSRF** برای مسیرهای حساس، محدودیت تلاش ورود (**Rate Limiting**) و قفل خودکار حساب پس از تلاش‌های ناموفق متوالی.
- **ثبت رویدادهای امنیتی (Audit Log)**: ذخیره لاگ ورودهای موفق/ناموفق، تغییرات رمز و عملیات حساس در `audit.log`.

## 🛠 تکنولوژی‌های استفاده‌شده

- **Frontend**: HTML5, CSS3 (Custom RTL Design System), Vanilla JavaScript (ES6+), IndexedDB
- **Backend**: Node.js, Express.js
- **Security**: `helmet`, `cors`, `cookie-parser`, `jsonwebtoken`, `bcryptjs`, `qrcode` (TOTP 2FA), CSRF Middleware, Rate Limiter
- **Database**: پشتیبانی منعطف از **MongoDB** (با Connection Pooling)، **PostgreSQL** (`server/schema.sql`) و حالت **JSON Fallback** برای اجرای فوری بدون نیاز به دیتابیس خارجی

│   ├── content.js          # رندر بلوک‌های محتوایی و مدیا

    ├── middleware/         # auth, csrf, rate-limiter, account-lockout, totp, audit
    └── routes/             # public, auth, panel, site

## 🚀 راه‌اندازی و اجرا روی سیستم شخصی

### ۱. کلون کردن پروژه و نصب وابستگی‌ها

```bash
git clone https://github.com/Reza-Mokhtari-Hub/dentalfy.git
cd dentalfy
npm install
```

### ۲. تنظیم متغیرهای محیطی

یک فایل `.env` در ریشه پروژه بسازید (می‌توانید از `.env.example` کپی بگیرید):

```env
PORT=3000
APP_ORIGIN=http://localhost:3000
JWT_SECRET=your-strong-random-secret-key
JWT_EXPIRES_IN=7d
ADMIN_EMAIL=admin@rmo.local
ADMIN_PASSWORD=your-secure-password
# اختیاری: در صورت تنظیم، سرور به MongoDB متصل می‌شود
MONGODB_URI=
# اختیاری: برای استفاده از PostgreSQL
DATABASE_URL=
```

> اگر `MONGODB_URI` را خالی بگذارید، سرور به‌صورت خودکار با دیتابیس محلی JSON (`server/mock_db.json`) بالا می‌آید و تمام داده‌های اولیه را می‌سازد.

### ۳. اجرای سرور

```bash
npm start
```

سپس در مرورگر آدرس زیر را باز کنید:

- **سایت اصلی:** `http://localhost:3000`
- **ورود به پنل مدیریت:** `http://localhost:3000/panel/index.html`

> **اطلاعات ورود اولیه مدیر (در محیط لوکال):**  
> ایمیل: `admin@rmo.local` | رمز عبور: `rmo2026`  
> حتماً پس از اولین ورود در محیط واقعی، رمز عبور مدیر و `JWT_SECRET` را تغییر دهید.
