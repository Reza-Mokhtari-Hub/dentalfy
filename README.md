# اکادمی دندان — Dental Learning Academy

سایت آموزشی دروس دندانپزشکی با بخش پست‌ها و فرم درخواست اکانت نویسنده.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید، یا:

```bash
npx serve .
```

## امکانات کامل سایت

- **صفحه اصلی**: دروس، پست‌ها، کتابخانه فایل، درباره، FAQ، درخواست اکانت
- **صفحه پست** (`post.html?id=...`): پخش ویدیو، دانلود فایل، محتوای بلوکی
- **صفحه درس** (`course.html?id=...`): سرفصل + پست‌های همان درس
- **پنل**: ویرایشگر بلوکی — متن، عنوان، تصویر، ویدیو (YouTube/Aparat/mp4)، فایل PDF، نقل‌قول، لیست
- **آپلود**: IndexedDB تا ۲۵MB (بعداً سرور)

## ساختار

- `index.html` — صفحه اصلی
- `styles.css` — استایل (پالت دندانپزشکی: فیروزه‌ای، نعنایی، آبی کلینیکی)
- `app.js` — پست‌های نمونه، فیلتر، فرم درخواست (ذخیره در localStorage)
- `IMAGES-LIST.md` — لیست تصاویر مورد نیاز

## فوتر

`Powered by RMO © [سال جاری]` — سال به‌صورت خودکار از JavaScript پر می‌شود.

## پنل مدیریت و پست‌گذاری

- `panel/dashboard.html` — داشبورد (پس از ورود)
